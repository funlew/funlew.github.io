## 关于本站

- 静态站点生成器：[Hexo](https://hexo.io/)
- 主题：[Icarus](https://github.com/ppoffice/hexo-theme-icarus)（`claude/sleepy-cerf-j3bky5` 分支）
- 托管平台：GitHub Pages

## 常用命令

### 新建文章

```bash
hexo new "文章标题"
```

### 本地预览

```bash
hexo server
```

### 生成并部署

```bash
hexo generate
hexo deploy
```

更多用法请参考 [Hexo 官方文档](https://hexo.io/docs/)。
